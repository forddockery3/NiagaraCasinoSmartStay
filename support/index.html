Support

Common questions about Niagara Casino Smart Stay.

What is Niagara Casino Smart Stay?

A hotel guest service app for room requests, hotel event reservations, in-room dining, parking space reservations, and hotel information in one interface.

Can I play casino games or wager money in the app?

No. Niagara Casino Smart Stay is only for hotel guest services during a stay. It does not include slots, table games, sports betting, deposits, withdrawals, or any real-money gaming.

Do I need to sign up or log in to use it?

No account is required to use the main guest features. Support contact is available by email if you need help.

How do I create a guest request?

Open Guest Requests, pick a category (for example Housekeeping or Maintenance), describe what you need, and submit. Then track statuses: Submitted, Accepted, In Progress, On the Way, Completed.

How do event reservations work?

Open Event Booking, review the photo, description, date, time, and available places. Choose the number of guests, add an optional note, and reserve. Guest details can attach automatically when available.

How do I order in-room dining?

Browse Breakfast & Morning Meals, Main Courses & Grill, or Light Bites & Snacks. Add dishes to the cart, adjust quantities, add an optional note if needed, then confirm. The summary shows delivery estimate, waiting time, and total.

How does parking reservation work?

Use the map for Floor 1, 2, or 3, select an available space, set start and end date/time, and save. Review active, upcoming, and completed bookings in My Reservations. Eligible bookings can be edited or cancelled in the app.

What is the guest code?

A temporary guest code with a short number that changes periodically. It does not contain personal information. Open it full-screen when reception asks to see it.
